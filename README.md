# MechWarrior: Dark Age — Fan Archive

A static archive of card recreations and interactive clix-base mockups for the
MechWarrior: Dark Age collectable game (WizKids). **Live site:
<https://peterbehere-repo.github.io/MechWarrior-Dark_Age/>**

## Interactive clix bases

Printable, interactive base mockups rebuilt from Warrenborn unit stats. Each base is a
single self-contained HTML page: click cells to advance the damage dial, view heat
effects, weapon and special-equipment tooltips, and KO bullet holes punched past the
last click.

- **Mechs & quads** — [`bases.html`](bases.html): 788 builds covering 747 units across
  21 factions, including all 27 quad-class units. Built on the locked mech and quad
  templates (a template copy lives at `mocks/biped-r2.html`).
- **Infantry** — [`infantry.html`](infantry.html): 372 circle-base units across 18
  factions, built on the locked Fenrir infantry template, with an exceptions doc
  covering units whose builds deviate from it.

## Provenance

Card art comes from the owner's OneDrive archive of catalog scans (upscaled 3×).
Card text was recovered verbatim from archived card database listings. Frames, typography
and point-badge placement are typeset in the spirit of the printed 2.0 card design — no
complete card scans were ever archived anywhere, so layout is a faithful reconstruction,
not a scan. Rarity was not captured in the recovery and is intentionally absent.

Cards whose text says "Provides X SE" carry a highlighted **SE RULE** block quoting the
complete official definition of that special equipment, from the AoD SEC reference sheet
and the set rules inserts (recovered from the Internet Archive). Base pages use the same
recovered wording for heat effects and special equipment.
