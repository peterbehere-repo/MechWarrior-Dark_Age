# MechWarrior: Age of Destruction — CEC Card Recreations

Complete recreation of all 233 combat enhancement (gear) cards from the MechWarrior:
Age of Destruction 2.0 clix era (WizKids, 2005–2007), covering eight sets:

| Set | Cards |
|---|---|
| Age of Destruction | 33 |
| Fire for Effect | 25 |
| Annihilation | 32 |
| Domination | 41 |
| Vanguard | 32 |
| Wolf Strike | 30 |
| Solaris VII | 28 |
| BattleForce | 12 |

## What this is

- **Index** — `docs/Index.html`: searchable, A–Z listing of all 233 cards
- **Set pages** — `docs/CEC Recreations - <Set>.html`: full card recreations with original art
- **Art library** — `Card Art/`: all 233 card-art panels at 600 px (recovered from OneDrive catalog scans)
- **Dataset** — `mwda-gear-cards.json`: the structured source of truth (names, IDs, points, slots, factions, verbatim card text)

## Provenance

Card art comes from the owner's OneDrive archive of catalog scans (upscaled 3×).
Card text was recovered verbatim from archived card database listings. Frames, typography
and point-badge placement are typeset in the spirit of the printed 2.0 card design — no
complete card scans were ever archived anywhere, so layout is a faithful reconstruction,
not a scan. Rarity was not captured in the recovery and is intentionally absent.

Cards whose text says "Provides X SE" carry a highlighted **SE RULE** block quoting the
complete official definition of that special equipment, from the AoD SEC reference sheet
and the set rules inserts (recovered from the Internet Archive).
