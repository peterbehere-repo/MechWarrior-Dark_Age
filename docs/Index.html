On the set pages, cards whose text says “Provides X SE” carry a highlighted SE RULE block quoting the complete official definition of that special equipment (AoD SEC reference sheet and set rules inserts). Colored range-type, speed-mode and attack-symbol glyphs from the printed SEC sheet are reproduced as bracketed words. Rarity was not archived anywhere and is intentionally absent. The 129 GS pilot-gear cards are pilot cards, not CECs, and are not listed here. The structured dataset lives in mwda-gear-cards.json.
